# Lost & Found Management System

A simple web-based Lost & Found Management System developed as a DSA project using **Linked List, Searching, Sorting and Deletion**.

## 📌 Project Overview

This system helps students and campus users report, search and manage lost and found items in one place.

Users can:
- Report lost items
- Report found items
- Search for items
- Filter Lost / Found items
- Sort items by date
- Edit item details
- Contact the reporter
- Mark items as returned
- Delete records
- Store data using browser LocalStorage

## 🧠 DSA Concepts Used

### 1. Linked List
Each lost or found item is stored as a node in a singly linked list.

text
```HEAD → Node → Node → Node → NULL```

### 2. Searching

The system traverses the linked list and searches for matching item details such as:

Item name
Category
Location
Reporter
Contact number

Time Complexity: O(n)

### 3. Sorting

Items can be arranged by reported date using JavaScript sorting.

Typical Time Complexity: O(n log n)

### 4. Deletion

When an item is deleted, the corresponding node is removed from the linked list.

Time Complexity: O(n)
